# Social Network Data Cleaning - Coders of Delhi

##  Project Overview

This project focuses on cleaning and processing social network data using Python. The dataset is stored in JSON format, and the project improves data quality by identifying and removing duplicate and invalid records. It also organizes user information for further analysis.

---

##  Features

- Load and process JSON-based social network data
- Remove duplicate friend IDs
- Remove duplicate liked pages
- Remove users with missing or invalid information
- Organize user and page data using Python dictionaries and lists
- Export cleaned data into a new JSON file
- Implement reusable Python functions for data cleaning
